# Fundamentos e Tags

## O que aprendi
- HTML não é linguagem de programação (não tem lógica), é a fundação do site
- Usa tags para marcar o conteúdo e estruturar textos, imagens e navegação
- HTML É HYPERTEXT MARKUP LANGUAGE
- É uma linguagem utilizada para estruturar o conteúdo de uma página de internet 

## Tags principais
- `<h1>` título
- `<p>` parágrafo
- `<img>` imagem
- `<a>` link

## Exemplo
```html
<h1>Meu título</h1>
<p>Meu primeiro parágrafo.</p>
<a href="https://github.com">Ir para o GitHub</a>
```
