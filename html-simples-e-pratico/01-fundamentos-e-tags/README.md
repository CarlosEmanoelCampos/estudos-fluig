# Fundamentos e Tags

## O que aprendi
- HTML não é uma linguagem de programação, pois não trabalha com lógica de programação.
- É a **base da estrutura de uma página web**, organizando textos, imagens, links e outros conteúdos.
- HTML significa **HyperText Markup Language** (Linguagem de Marcação de Hipertexto).
- É uma linguagem utilizada para estruturar o conteúdo de uma página da internet.
- Utiliza **tags** para identificar e organizar os diferentes elementos de uma página.

## Tags principais
- `<h1>` representa o **título principal** de uma página ou conteúdo.
- `<h2>` representa um **subtítulo**, utilizado para organizar o conteúdo.
- `<p>` representa um **parágrafo**, utilizado para escrever textos.
- `<img>` representa uma **imagem**, permitindo adicionar imagens à página.
- `<a>` representa um **link**, permitindo navegar para outras páginas ou sites.

## Exemplo

```html
<!DOCTYPE html>
<html>
<head>
    <title>Minha primeira página</title>
</head>
<body>

    <h1>Meu primeiro site</h1>
    <h2>Sobre mim</h2>

    <p>Estou aprendendo HTML e desenvolvimento web.</p>

    <img src="imagem.jpg" alt="Minha imagem">

    <a href="https://github.com">Acessar GitHub</a>

</body>
</html>
```
