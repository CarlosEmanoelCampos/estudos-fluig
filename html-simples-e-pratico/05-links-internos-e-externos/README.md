# Links Internos e Externos

## O que aprendi
- Os links permitem **navegar entre páginas e sites**.
- São importantes para conectar conteúdos e facilitar a navegação na internet.
- A tag `<a>` é utilizada para criar links em HTML.
- O atributo `href` define o **destino do link**.

## Tipos de links
- **Links internos:** permitem navegar entre páginas do mesmo site.
- **Links externos:** direcionam o usuário para outros sites ou páginas da internet.

## Tags e atributos principais
- `<a>` representa um **link**, utilizado para criar navegação.
- `href` define o **endereço de destino** do link.
- `target="_blank"` permite abrir o link em uma nova aba.

## Exemplo

```html
<!-- Link externo -->
<a href="https://github.com" target="_blank">Acessar GitHub</a>

<!-- Link interno -->
<a href="sobre.html">Conheça nossa página</a>
```
