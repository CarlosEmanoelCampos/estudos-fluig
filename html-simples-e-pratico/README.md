
# 🌐 Fundamentos HTML: Simples e Prático

Curso realizado pela **TOTVS Fluig Academy**, com foco nos fundamentos da linguagem HTML e na construção de páginas web.

Durante o curso, aprendi a utilizar as principais tags do HTML, estruturar conteúdos, organizar informações e criar formulários. Também desenvolvi exemplos práticos para aplicar os conceitos estudados.

## 🎯 Objetivo

Compreender os fundamentos do HTML e desenvolver uma base para a criação e estruturação de páginas web, utilizando boas práticas de organização e semântica.

## 📚 Conteúdo estudado

1. 🏷️ [Fundamentos e Tags](01-fundamentos-e-tags)
   - Estrutura básica de um documento HTML e principais tags.

2. 🧩 [Semântica de Conteúdo](02-semantica)
   - Organização do conteúdo utilizando elementos semânticos.

3. 📊 [Tabelas e Agrupadores](03-tabelas-e-agrupadores)
   - Estruturação de informações em tabelas e agrupamento de elementos.

4. 📝 [Formulários](04-formularios)
   - Criação de formulários, campos de entrada e elementos de interação.

## 🛠️ Tecnologias e conhecimentos

- HTML5
- Estruturação de páginas web
- Tags e elementos HTML
- Semântica
- Formulários
