# Projeto Prático — TOTVS Fluig Academy

Projeto desenvolvido durante meus estudos de HTML, com o objetivo de praticar os conceitos aprendidos no curso **Fundamentos HTML: Simples e Prático**, da TOTVS Fluig Academy.

## Sobre o projeto

Este projeto reúne exemplos práticos de HTML, organizados em páginas separadas por assunto.

## Conteúdos praticados

- Estrutura básica do HTML
- Títulos e parágrafos
- Links internos e externos
- Listas
- Tabelas
- Formulários
- HTML semântico (`header`, `nav`, `main`, `section` e `footer`)

## Tecnologias utilizadas

- HTML5
- Visual Studio Code

## Objetivo

Aplicar na prática os conhecimentos adquiridos durante o curso e desenvolver minha experiência com desenvolvimento web.
